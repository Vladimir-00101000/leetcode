
```bash
grep [опции] "шаблон" файл

-i	Игнорировать регистр	grep -i "error" app.log
-n	Показать номера строк	grep -n "fail" server.log
-r	Искать рекурсивно в каталогах	grep -r "TODO" .
-v	Исключить строки с шаблоном	grep -v "INFO" log.txt
-E	Использовать расширенные регулярные выражения (подробнее далее)	grep -E "(ERROR FAIL)" log.txt
```

Объединить потоки ввода и ошибок
```bash

>       output.log — направляет стандартный вывод (stdout, поток 1) в файл output.log.

```

Скопировать файл/каталог
```bash
cp file.txt backup.txt
cp -r Documents/ Backup/

-v (англ. verbose) — показывает, что именно копируется;
-i (англ. interactive) — запрашивает подтверждение перед перезаписью уже существующего файла;
-u (англ. update) — копирует файл, только если исходный файл новее (то есть время его последнего изменения mtime более позднее), чем уже существующий файл.
```

Шаблоны glob
```bash
*	Любое количество символов (включая ноль)   ls *.txt	           Все файлы, заканчивающиеся на .txt
?	Ровно один любой символ	                   ls file?.txt	       file1.txt, fileA.txt, но не file10.txt
[ ]	Любой символ из набора или диапазона	   ls report[12].txt   report1.txt, report2.txt, но не report3.txt или report12.txt
```

```bash
cat file.txt

-n	Показывать номера строк	                    cat -n file.txt
-b	Нумеровать только непустые строки	        cat -b file.txt
-s	Сжимать повторяющиеся пустые строки	        cat -s log.txt
-E	Показывать символ $ в конце каждой строки	cat -E file.txt
```

Постраничный просмотр содержимого
```bash
less filename.txt

Space	Перейти на следующую страницу
↑ / ↓	Прокрутка по строкам
/слово	Найти слово, поиск вперёд
?слово	Найти слово, поиск назад
n	    Перейти к следующему совпадению
N	    Перейти к предыдущему совпадению
g	    Перейти в начало файла
G	    Перейти в конец файла
q	    Выйти из просмотра
+G  	Перейти в конец файла	less +G app.log
+10	    Открыть и перейти на 10-ю строку	less +10 file.txt
+/слово	Открыть и сразу выполнить поиск	less +/ERROR log.txt
```

Упаковать каталог folder/ в архив archive.tar
```bash
tar -cvf archive.tar folder/

-c	Создать новый архив (create)
-v	Показывать процесс упаковки (verbose)
-f	Указать имя файла архива (file)
-t   Показать список файлов в архиве
```
Распаковка архива
```bash
tar -xvf archive.tar

-x	        Извлечь файлы из архива
-v	        Показывать процесс извлечения (verbose)
-f	        Указать имя архива
-C </путь>  Распаковать в другое место
```

```bash
Важно: tar не сжимает данные!

.tar.gz	    tar -czvf archive.tar.gz folder/	Использует gzip, быстрее, но меньше степень сжатия
.tar.bz2	tar -cjvf archive.tar.bz2 folder/	Использует bzip2, сжимает сильнее, но медленнее
.tar.xz	    tar -cJvf archive.tar.xz folder/	Использует xz, даёт лучшее сжатие
```

Различия между двумя файлами/каталогами(-r)
```bash
diff file1.txt file2.txt

<	Строка из первого файла (file1.txt)
>	Строка из второго файла (file2.txt)
---	Имя и версия первого файла
+++	Имя и версия второго файла
@@	Диапазон строк, где найдено отличие
-	Строка, присутствующая только в первом файле
+	Строка, присутствующая только во втором файле
```
Коды возврата
```bash
0	Успех	                                        Команда выполнилась без ошибок
1	Общая ошибка	                                Что-то пошло не так (универсальный код)
2	Ошибка аргументов	                            Команде переданы неверные параметры или файл не найден
126	Команда найдена, но не может быть выполнена	    Нет прав или это не исполняемый файл
127	Команда не найдена	                            Bash не смог найти указанную команду
130	Прерывание пользователем (Ctrl + C)	            Выполнение остановлено вручную
```

Bash скрипт
```bash
#!/bin/bash
# Создаём каталог с сегодняшней датой
mkdir -p ~/Projects/$(date +%Y-%m-%d)
cd ~/Projects/$(date +%Y-%m-%d)

# Переносим отчёты
mv ~/Reports/* .

# Печатаем сообщение об успехе
echo "Отчёты успешно перенесены!"


#!/bin/bash называется shebang
#!/bin/bash	Запускает скрипт через Bash
#!/usr/bin/env python3	Запускает через Python 3
#!/bin/sh	Через стандартную оболочку sh
#!/usr/bin/env perl	Через Perl
```
