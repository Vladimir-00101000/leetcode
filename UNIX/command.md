# Команды UNIX

```bash
find . -name "*.txt"
```

```bash
cat file.txt | wc -l
```
wc -> кол-во строк, слов, байт; -l -> только кол-во строк
| -> пайп

Вывести имя хоста
```bash
hostname
```
Вывод чего-то куда-то(>)
```bash
echo "Hello, World!"
```
Получить текущую дату
```bash
date
```
Очистить окно терминала
```bash
clear
```

Завершение текущей терминальной сессии
```bash
exit
```
(CTRL + D)

```bash
~ домашний каталог
$ приглашение к вводу от обычного ползователя
# приглашение к вводу от пользователя root
```

```bash
$HOME — путь к домашнему каталогу текущего пользователя;
$USER — имя текущего пользователя;
$SHELL — оболочка, которая используется по умолчанию;
$PATH — список каталогов, где система ищет команды.
```

Где находится что-то(например ls, python3, ...)
```bash
wich
```
Создание переменной окружения
```bash
MYVAR="Hello"
```
История команд
```bash
history
-с - очистить историю команд
```
Быстрое выполнение команды из истории команд
```bash
!<номер строки>
```

```bash
!! — выполнить последнюю команду.
!$ — подставить последний аргумент предыдущей команды.
!ls — выполнить последнюю команду, начинавшуюся с ls.
```

```bash
ls -R /  -  тысячи строк в терминал


Ctrl + S — приостановить вывод в терминале.
Ctrl + Q — возобновить вывод.
```
Создание/удаление алиаса
```bash
alias lll='ls -lh'
unalias lll
```
